# Q-IAD

This repository provides the evaluation code for Quaternion-Guided Multimodal Interaction for MLLM-Based Industrial Anomaly Detection.

## Environment Setup

Please install the required packages before running the evaluation script.

If you use `requirements.txt`, run:

```bash
pip install -r requirements.txt
```

## Run Evaluation

After installing the required packages, run the following command from the project root directory:

```bash
python code/eval.py
```
